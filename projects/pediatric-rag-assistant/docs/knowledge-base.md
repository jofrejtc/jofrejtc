# Knowledge-base design

I created a dedicated knowledge base and grouped files by common parent questions. The academic screenshots and report document these topic areas.

| Topic | Organisation goal |
| --- | --- |
| Fever | Keep age-dependent context and warning signs easy to retrieve. |
| Respiratory symptoms | Group related questions while retaining topic boundaries. |
| Vomiting, diarrhea and hydration | Connect symptom descriptions to the relevant information. |
| Newborn care | Keep early-age material distinct. |
| Feeding | Group feeding-related questions. |
| Sleep | Organise sleep-related content. |
| Warning signs | Keep escalation-related information easy to locate. |
| Common questions and terminology | Support the wording used by parents. |

Folder access was configured for the dedicated project concierge.

## Source provenance

The final report describes uploaded pediatric files, but it does not provide their full source bibliography or an exported corpus. Exact source attribution and corpus reconstruction therefore remain incomplete.

A reproducible knowledge base should record the original URL or document reference, publisher, document date, retrieval date, permitted use and the specific section indexed. A further iteration should also record the review status and document version.

## Proposed improvements

The academic conclusion proposes narrower content sections and metadata such as topic, age group, urgency and symptom type. These remain next-iteration design ideas.
